Design a modern, farmer-first responsive web application called **“Krishi Sahayak”**, an AI-powered crop advisory platform for Indian farmers.

The goal is to create a trustworthy, simple, highly visual agricultural technology platform that helps farmers make better crop decisions using their farm profile, location, soil, water availability, live weather, AI crop disease detection, government schemes and human expert support.

## CORE DESIGN DIRECTION

Create a visual identity called:

**“Digital Krishi + Nature”**

The design should feel:
- Natural
- Trustworthy
- Modern
- Simple
- Friendly
- Professional
- Accessible to farmers
- Suitable for Indian rural and semi-urban users

Use a nature-inspired visual language with agricultural greens, soft earth tones, warm sunlight accents, clean off-white surfaces, subtle blue weather accents and restrained warning colors.

Avoid making the interface look like a corporate analytics dashboard.

Use:
- Large readable typography
- Rounded cards
- Clear icons
- Soft shadows
- Generous spacing
- Simple navigation
- Large touch-friendly controls
- Agricultural illustrations
- Farm/map visuals
- Weather illustrations
- Subtle nature-inspired animations

Do not overload screens with information.

The interface must prioritize clarity over decoration.

## RESPONSIVE DESIGN

Design for:
1. Desktop
2. Tablet
3. Mobile

Mobile should feel like the primary farmer experience.

All important buttons must be large and easy to tap.
